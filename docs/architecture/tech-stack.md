# Tech Stack & Constraints

- **Python Version**: >= 3.12
- **Core Framework**: FastAPI (>=0.109.0)
- **Frontend**: Jinja2 (>=3.1.3) + HTMX (No React/Vue/Angular)
- **Styling**: Vanilla CSS or CDN Tailwind (Candlelight Mode ONLY)
- **Database**: ChromaDB (>=0.4.22)
- **Deployment**: Bare Metal (No Docker/Kubernetes)
- **Architecture**: Modular Monolith (No Microservices)
- **Auth**: None / Basic Script Only (No User Accounts, No complex OAuth/JWT)
