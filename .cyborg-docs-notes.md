## Real User Problem

The product helps a user compare multiple agricultural expert perspectives without manually rewriting the same question for each specialty. It turns one farming question into either:

- a fast multi-expert response set
- a slower multi-round roundtable with a final consensus

## Repo-Grounded Facts That Must Stay True

- Stack: FastAPI, Jinja2, HTMX, ChromaDB, OpenRouter, slowapi rate limiting
- UI: server-rendered templates with HTMX partial swaps
- Experts: 10 specialized agriculture advisors
- Query mode: `main.py` route `/query` calls `query_experts()` for parallel responses
- Roundtable mode: `main.py` route `/roundtable` calls `run_roundtable()` for multi-round discussion plus a final consensus
- CSRF is enforced on the interactive routes
- Saved history exists and results can be exported as markdown
- Local quick-start path is `uv sync` then `./start.sh` or `uv run uvicorn main:app --reload --port 8123`

## Architecture Signals To Reflect

- `query_experts()` is the main parallel consultation path
- `run_roundtable()` is the discussion path and depends on `_generate_consensus()`
- The documentation should distinguish the quick query path from the roundtable path clearly

## Project Page Angle

Frame the app as a multi-expert agriculture advisory surface for comparing perspectives, not as a generic LLM wrapper.

The project page should explain:

- what the app is for
- how query mode and roundtable mode differ
- why persistent history and markdown export matter
- the setup and run path
- the practical output a user gets after a session

## Workflow Page Angles

The roundtable workflow should be execution-first and centered on:

1. start the app
2. select at least two experts
3. enter a question
4. run the roundtable
5. read the transcript and final consensus
6. save or export the result

The quick-query workflow should be execution-first and centered on:

1. start the app
2. select one or more experts
3. enter a question
4. submit the query
5. compare the response cards
6. decide whether to save or move to the roundtable mode

Keep both workflows under `AI Frameworks`.
